# PTO Policy and Procedure Redesign

This technical writing portfolio project demonstrates the redesign of a text-heavy employee paid time off (PTO) policy and procedure into structured, user-focused documentation.

The project focuses on improving information architecture, readability, scannability, and task completion while preserving the intent of the source content.

## Redesign Highlights

The redesigned document:

- Separates policy requirements from procedural instructions
- Uses descriptive headings and a clear information hierarchy
- Converts embedded instructions into task-based procedures
- Uses numbered steps for sequential tasks
- Groups related requirements and reference information
- Improves scannability and ease of navigation
- Uses consistent terminology and formatting
